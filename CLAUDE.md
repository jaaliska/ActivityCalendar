# ActivityCalendar

Календарь спортивных активностей с Garmin. Solo pet-project, учебный.
План работ: @docs/plan/milestone-dev-plan.md
Решение по источнику данных: @docs/adr/ADR-001-data-source.md

## Стек
Kotlin, Jetpack Compose, Room, Health Connect. Минимальный SDK 28 —
приложение Health Connect существует только с Android 9, ниже его нет физически.

## Архитектурные правила
- UI читает данные ТОЛЬКО из Room. Никогда напрямую из Health Connect или парсера архива.
- Любой источник данных реализует интерфейс `ActivitySource`.
- Доменный `ActivityType` — свой enum, не маппится один-в-один ни на Garmin, ни на `EXERCISE_TYPE_*`.
- Время активности хранится как локальное время старта.

## Как работаем
- Не берись за задачи из следующих блоков плана, пока текущий блок не закрыт по DoD.
- Перед реализацией — короткий план в чате, код после подтверждения.
- Не добавляй зависимости без явного согласования.
- Комментарии только там, где неочевидно «почему», а не «что».
