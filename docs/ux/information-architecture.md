Документ описывает **структуру**: состав экранов, переходы и состояния. Расположение
элементов, размеры и иконки — в макетах Блока 3, здесь их нет.

## 1. Решение в одну строку

Календарь — единственный частый экран. Вспомогательные функции (импорт CSV, инструкция
по выгрузке, Health Connect, демо-данные) живут в **настройках**, а на первом запуске
поднимаются **на место календаря**, потому что до появления данных больше показывать нечего.

Три следствия, из которых выводится всё остальное:

- **Инструкция по выгрузке — не отдельная функция, а вспомогательный шаг импорта по
  требованию.** Она живёт на экране импорта, но всегда свёрнута: тот, кто выгружать уже умеет,
  не должен пролистывать её ради кнопки выбора файла.
- **Health Connect нужен экран статуса, а не кнопка «подключить».** Подключение — разовое,
  но «подключено, данных нет», «разрешения отозваны», «когда был последний синк»
  нужны постоянно.
- **Детали дня — панель под календарём, а не модальное окно.** Область под сеткой месяца
  одна и та же: без выбранного дня в ней сводка месяца (Блок 8), с выбранным — активности
  этого дня. Выбранный день при этом остаётся виден в сетке.

## 2. Экраны

| Экран | Назначение | Как часто | Блок |
|---|---|---|---|
| **Календарь месяца** | Старт приложения. Месяц целиком, тип каждой тренировки, признак нескольких активностей в дне. Под сеткой — панель дня и сводка месяца | ежедневно | 4, 5, 8 |
| **Выбор месяца и года** | Прыжок к произвольному месяцу вместо листания | редко | 5 |
| **Настройки** | Хаб: где живут данные и как выглядит приложение | редко | 3, 9 |
| **Импорт из Garmin CSV** | Один экран на всю задачу: выбрать файл → отчёт, инструкция по выгрузке рядом по требованию | 1–2 раза в год | 3 |
| **Health Connect** | Обоснование разрешений, статус подключения, ручное обновление | разово + ремонт | 6 |

Поверхности, которые экранами приложения не являются: системный выбор файла (SAF),
системный диалог разрешений Health Connect, установка Health Connect из Play Store.

**Выбор месяца и года** — диалог поверх календаря: он возвращает в тот же месяц, вырывать
из контекста незачем. Шаговое листание диалога не требует: соседние месяцы достижимы
стрелками в строке навигации, диалог нужен для прыжка через годы. **Детали дня**
отдельным экраном не являются вовсе — это панель под сеткой, часть экрана календаря.
Остальные три — полноценные экраны в back stack.

**Демо-данные** — не экран, а действие: синтетический CSV из assets, прогнанный через
парсер Блока 2. Нужен тому, у кого нет ни часов, ни выгрузки, но кто хочет посмотреть,
как приложение работает. Записи получают `source = DEMO`, поэтому отличимы от настоящих
и удаляются одним действием; иначе они смешались бы с реальной историей и сводки Блока 8
считали бы их за свои. Реализация — Блок 9, вместе с README и скриншотами.

## 3. Переходы

```
Календарь месяца ─── старт
├─ Выбор месяца и года ....... диалог; тап по названию месяца в строке навигации
├─ Панель дня ................ не переход: тап по дню в той же сетке
├─ Импорт из Garmin CSV ...... из пустого состояния «база пуста»
├─ Health Connect ............ из пустого состояния «база пуста»
│                              и из баннера «синхронизация остановлена»
├─ Демо-данные ............... действие из пустого состояния, без перехода
└─ Настройки ................. иконка в top bar
   ├─ Данные
   │  ├─ Импорт из Garmin CSV  ... тот же экран, второй вход
   │  ├─ Health Connect ......... тот же экран, второй вход
   │  └─ Демо-данные ............ загрузить и удалить
   └─ Вид ....................... тема, набор иконок
```

Глубина — максимум два уровня. Кнопка «назад» с любого экрана ведёт туда, откуда пришли:
с импорта, начатого из пустого состояния, — в календарь, а не в настройки.

**Где живёт каждая вспомогательная функция и почему:**

| Функция | Постоянное место | Контекстный вход | Обоснование |
|---|---|---|---|
| Импорт CSV | Настройки → Данные | Пустое состояние календаря | Раз в год — в top bar календаря не заслуживает места. Но B5 требует достижимости в любой момент, поэтому постоянное место обязательно |
| Инструкция по выгрузке | Верх экрана импорта | — | Отдельного входа нет: её не открывают, не собираясь импортировать. B4 требует, чтобы из инструкции был достижим выбор файла — на одном экране это выполняется само |
| Health Connect | Настройки → Данные | Пустое состояние календаря; баннер об отозванных разрешениях | Подключение разовое, но ремонт инициирует приложение, а не пользователь: он не пойдёт в настройки проверять, работает ли синк. Значит, проблема приходит к нему на календарь |
| Демо-данные | Настройки → Данные | Пустое состояние календаря | Нужны ровно один раз и ровно тому, кто открыл приложение впервые и своих данных не имеет. На экране импорта им не место: человек без часов туда не пойдёт, «Импорт из Garmin CSV» — не его сценарий |

## 4. Состояния экранов

Пустое состояние всегда называет **причину** и **что сделать дальше**. «Нет данных» без
причины запрещено: пользователь не должен отличать «я не тренировалась» от «синк сломался»
самостоятельно.

### Календарь месяца

| Состояние | Что показано |
|---|---|
| Загрузка | Отдельного состояния нет: месяц читается из локальной базы за единицы миллисекунд. Сетка рисуется сразу, значки появляются вместе с данными. Если чтение затянулось дольше ~200 мс — тонкая линия прогресса под строкой месяца, сетка при этом не меняется |
| Пусто: база пуста целиком | Сетка заменена блоком «Пока нет ни одной тренировки» с двумя путями (импорт CSV, Health Connect) и тихой третьей строкой про демо-данные. См. первый запуск |
| Пусто: месяц без тренировок | Сетка на месте, дни пустые, никакого сообщения. Пустой календарь объясняет себя сам, а месяц назван в шапке |
| Пусто: месяц раньше истории | Сетка на месте, подпись «История начинается 11 марта 2026» + тихая ссылка «дополнить историю из CSV» — здесь она уместна, потому что это ровно то, чем такой месяц наполняется |
| Ошибка | Сообщение о сбое чтения вместо сетки + повтор без перезапуска приложения |
| Успех | Сетка с иконками типов и признаком нескольких активностей в дне; под сеткой — панель. Дни соседних месяцев показаны приглушённо, со своими активностями: неделя на стыке месяцев видна целиком |
| Баннер (поверх любого состояния) | «Синхронизация остановлена: разрешения отозваны» → Health Connect. Только для проблем, требующих действия пользователя |

Будущие месяцы и месяцы раньше истории открываются как обычные пустые: границы листания нет.

### Импорт из Garmin CSV

| Состояние | Что показано |
|---|---|
| Исходное | Кнопка «Выбрать файл» и свёрнутая инструкция «Как выгрузить CSV из Garmin Connect». Свёрнута всегда, а не только при повторном импорте: она не должна стоять на пути у того, кто выгружать уже умеет |
| Инструкция раскрыта | Шаги от входа в веб-версию Garmin Connect до сохранения файла + три предупреждения: домотать список до конца, метрический профиль, английский язык интерфейса. Кнопка выбора файла остаётся достижимой, не уезжая за инструкцию |
| Загрузка | Индикатор разбора файла; повторный запуск импорта заблокирован |
| Успех | Отчёт остаётся на экране: добавлено, дублей, пропущено, период «с … по …» — он нужен для сверки с числом активностей в Garmin Connect |
| Успех без строк | Отчёт «добавлено 0» — это не ошибка |
| Ошибка | Причина (файл не читается / нет нужных колонок) + «база не изменилась». Экран остаётся, выбрать другой файл можно сразу |

Пустого состояния у экрана нет: до выбора файла экран и есть своё исходное состояние.

### Health Connect

| Состояние | Что показано |
|---|---|
| Не подключён | Что читаем (тренировки, дистанция, история глубже 30 дней, чтение в фоне) и зачем — до системного диалога. Отказ = уйти назад, системный диалог не открывается |
| Недоступен на устройстве | Предложение установить Health Connect + переход к установке; предупреждение, что Garmin пишет туда только с Android 14, а на 9–13 автосинк с часов не заработает; CSV назван как способ получить историю прямо сейчас |
| Загрузка | Идёт синхронизация; второй параллельный синк не стартует |
| Пусто: подключено, сессий нет | Обе возможные причины: интеграция не включена в Garmin Connect; часы ещё не синхронизировались |
| Пусто: разрешение на историю не выдано | Импортируются данные не глубже 30 дней, более старые доступны только через CSV |
| Ошибка: разрешения отозваны | Синхронизация остановлена именно поэтому; повторный запрос достижим; уже импортированные активности остаются в календаре |
| Ошибка синка | Ошибка показана, время последней **успешной** синхронизации не изменилось |
| Успех | Подключено, время последней успешной синхронизации, ручное обновление |

### Настройки

Статический список из секций; загрузки, пустого состояния и ошибки у экрана нет.
Состояние есть у строк секции «Данные» — подпись показывает статус: когда был последний
импорт, подключён ли Health Connect и когда синхронизировался.

| Секция | Пункты сейчас | Задел |
|---|---|---|
| Данные | Импорт из Garmin CSV, Health Connect, демо-данные | Экспорт своей БД, отключение источника (Блок 9) |
| Вид | Тёмная тема, набор иконок | Выбор цветовой схемы — схемы уже подобраны, см. [theme.md](theme.md) |

Экран на вырост: секции добавляются по мере появления настроек, структура «секция —
несколько строк» это выдерживает без перепроектирования.

Строка демо-данных двусоставная: «Загрузить демо-данные» либо, если они уже загружены,
«Демо-данные загружены» с удалением. Постоянного баннера о демо-режиме на календаре нет —
он портил бы ровно тот вид, ради которого демо и существует.

### Панель под календарём

Одна область, три состояния содержимого. Смена месяца снимает выбор дня, повторный тап
по выбранному дню — тоже. День соседнего месяца выбирается на месте: панель показывает его
тренировки, сетка остаётся на текущем месяце.

| Состояние | Что показано |
|---|---|
| День не выбран | Сводка месяца: число тренировок, суммарное время и дистанция по типам (Блок 8). До Блока 8 панель в этом состоянии не показывается |
| Выбран день с активностями | Активности по времени старта, ранняя первой: тип, время, длительность, дистанция, название. Отсутствующая дистанция показана как отсутствующая, а не нулём; вместо отсутствующего названия — тип |
| Выбран день без активностей | «Тренировок не было». Выбрать можно любой день: сюда встанет ручное добавление, когда для него назначат блок |
| Ошибка | Сбой чтения дня сообщает о себе; сетка месяца остаётся рабочей |

Загрузки у панели своей нет: данные месяца уже прочитаны для сетки.

У выбора месяца и года состояний нет: это диалог над уже загруженными данными.

## 5. Первый запуск

Онбординга и туториала нет. Человек сразу попадает на календарь текущего месяца — тот самый
экран, которым будет пользоваться дальше. Отличие ровно одно: на месте сетки месяца стоит
блок «Пока нет ни одной тренировки» с двумя путями, и оба названы своим результатом,
а не своим механизмом:

- **Импортировать историю из Garmin CSV** — все прошлые тренировки сразу, ведёт на экран импорта.
- **Подключить Health Connect** — новые тренировки появляются сами, ведёт на экран Health Connect.
- Ниже, тише остальных: **посмотреть на демо-данных** — для того, у кого нет ни часов Garmin,
  ни выгрузки. Владельцу календаря эта строка нужна ноль раз, поэтому она не соперничает
  с двумя настоящими путями, но и прятать её в настройки бессмысленно: тот, кому она нужна,
  дальше первого экрана не пойдёт.

Ни один путь не обязателен и не блокирует другой: приложение полностью работоспособно
с любым одним из них. Порядок в блоке — импорт первым: он единственный даёт данные
в ту же минуту, тогда как Health Connect до следующей тренировки покажет пустой календарь.

Как только в базе появляется первая активность — своя или демонстрационная, — блок исчезает:
дальше все три функции живут в настройках. Удаление демо-данных возвращает его. Отдельного экрана-визарда нет намеренно — он дублировал бы пустое
состояние календаря и потребовал бы правила «когда его больше не показывать».
