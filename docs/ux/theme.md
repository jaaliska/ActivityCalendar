## Решения

| Что | Решение |
|---|---|
| Цветовая схема | **Синяя**, `hue 257 / chroma 60`. Три запасные ниже |
| Шрифт | Системный **Roboto**, шкала типографики Material 3 по умолчанию |
| Скругления | Дефолтная шкала форм Material 3 |
| Material You (цвета из обоев) | **Выключен**: подстройка под обои будет спорить с фиксированными цветами активностей |
| Цвета активностей | В тему **не входят**: это цвета данных, они одинаковы во всех темах — см. таблицу в [mockup-plan.md](mockup-plan.md) |

**Правило, без которого несколько тем становятся дорогими:** в экранах не должно быть ни одного
шестнадцатеричного цвета, только роли `MaterialTheme.colorScheme`. Единственное исключение —
палитра типов активностей, она живёт отдельно.

## Цветовые схемы

Значения — приближение, посчитанное в CIE LCh: ось тона там `L*`, как в материаловском HCT.
Для приложения точную схему берём из официального Material Theme Builder по тому же seed;
отличия — единицы процентов, характер цвета не меняется.

Формат ячейки: светлая тема / тёмная тема.

| | Малиновая | **Синяя (в работе)** | Оранжевая | Зелёная |
|---|---|---|---|---|
| Seed | `#BB576C` | `#067EB5` | `#A46947` | `#488446` |
| Тон / насыщенность | 10 / 43 | **257 / 60** | 55 / 35 | 140 / 43 |
| Фон | `#FEF8F9` / `#191112` | `#F5FAFF` / `#0E1419` | `#FFF8F5` / `#19120E` | `#F5FBF4` / `#10150F` |
| Ячейка дня | `#F1E6E7` / `#302829` | `#E3E9EF` / `#252B2F` | `#EFE6E2` / `#2F2925` | `#E4EAE3` / `#272B26` |
| Выбранный день | `#FEDADE` / `#5D3F43` | `#CCE6FE` / `#244A65` | `#F7DDD0` / `#564338` | `#D4E8D0` / `#3A4B38` |
| Primary | `#9E3D54` / `#FFB2BE` | `#076491` / `#90CDFE` | `#885030` / `#FBB792` | `#2F6B2F` / `#98D691` |

Серый фон ячеек — не отдельное решение, а производная seed: нейтральные поверхности
в Material 3 подкрашены его тоном. Поэтому подбирать оттенок выделенного дня в отрыве
от темы бессмысленно, он равен роли `secondaryContainer`.

## Смена темы

Светлая и тёмная тема следуют системной настройке телефона: своего переключателя
у приложения нет и не будет. Настраивается только цветовая схема — четырьмя кружками
в строке «Color scheme» секции «Вид» (бриф 8). До появления этой строки приложение живёт
на синей схеме.

Что надо сделать, когда до неё дойдёт дело: проверить фиксированные цвета активностей
на всех четырёх схемах в обеих темах. Сейчас они проверены только на синей, а конфликт
возможен: у оранжевой схемы primary близок к цвету бега, у зелёной — к цвету ходьбы.
